The Glossary.

 

The definitive guide to the buttons and what they can do.

Back.

Previous page or article. Sits left of content.

 

Next.

Next page or article. Sits right of content.

 

Table of Contents.

A list of pages.

 

Lock.

Locks the zoom. Default state.

Zoom out.

Minimizes content. First click the ‘Lock’ button to unlock.

 

Zoom in.

Magnifies content. First click the ‘Lock’ button to unlock.

 

Fit to Window.

Make content width fill the browser window.

 

Full screen mode.

Maximize the content to fill your full screen.

Single or Double page.

Double page layout feels like an unfolded newspaper spread.

 

Navigator.

Opens a scrollable page-by-page view.

 

First page.

First page of the edition.

 

Previous page.

One page back from the current page.

Next page.

One page forward from the current page.

 

Last page.

Last page of the edition.

 

Save.

Save the page to your library.

 

Download.

Save the page to your desktop.

Print.

Print the page, or select the clip icon to print part of a page.

 

Clip.

Select a portion of the page to print.

 

Share.

Click to share the page with others.
